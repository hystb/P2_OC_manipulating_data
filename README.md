# Projet P2 – Manipulation de données avec Python

## Présentation

L'objectif principal est de développer des compétences en manipulation, nettoyage et analyse de données à l'aide de Python et de bibliothèques telles que Pandas et NumPy. Le projet est présenté sous forme de notebook Jupyter, facilitant l'exploration interactive des données.

## Contenu du dépôt

- `Milan_Nicolas_1_notebook_072024.ipynb` : Notebook Jupyter principal contenant l'intégralité du projet, incluant le chargement des données, le nettoyage, l'analyse exploratoire et les visualisations.

## Objectifs pédagogiques

- Acquérir une maîtrise des bibliothèques Pandas et NumPy pour la manipulation de données.
- Appliquer des techniques de nettoyage de données pour assurer la qualité des analyses.
- Réaliser une analyse exploratoire des données (EDA) pour en extraire des insights pertinents.
- Créer des visualisations efficaces pour communiquer les résultats de l'analyse.
